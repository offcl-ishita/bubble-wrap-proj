## 🎮 Live Demo
[**Click here to play with the Bubble Wrap Toy!**](https://offcl-ishita.github.io/bubble-wrap-proj/) 

## ✨ Features & Interactions
This project was built to satisfy the core challenge requirements by including at least 3 meaningful user interactions, plus a bunch of bonus features!

1. **Pop the Bubbles (Interaction 1):** Click any bubble to pop it. It squishes down, changes color, and plays a highly satisfying `pop.mp3` sound effect. 
2. **The "Wave" Refill (Interaction 2):** When you run out of bubbles, hit the "Refill Board" button. Instead of instantly resetting, the bubbles repopulate in a smooth, cascading wave animation across the grid.
3. **Dark Mode Toggle (Interaction 3):** A sleek theme switcher that dynamically shifts the CSS variables to flip the entire UI into a late-night friendly dark mode.

### 🎁 Bonus Features Included
* **Easter Eggs / Loot Drops:** 10% of the bubbles hide random "treasures" (🗡️, 🍬, 👽, 🍕, etc.). Popping a lucky bubble triggers a CSS floating animation and adds the item to your permanent inventory stash.
* **Score Tracking:** A live counter keeps track of exactly how many bubbles you've destroyed.
* **Responsive Design:** The CSS Grid automatically scales and reflows to fit perfectly on desktop or mobile devices.

## 🛠️ Setup & Installation
Since this is built with Vanilla HTML/CSS/JS, no complex build tools or dependencies are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/bubble-wrap-toy.git
   ```
2. Open the folder on your local machine.
3. Make sure you have a sound file named `pop.mp3` in the root directory.
4. Simply double-click `index.html` to open it in your web browser!
